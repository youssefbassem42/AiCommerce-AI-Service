How to test this page end-to-end

  1. Provision a widget installation via the admin API (see below), with ORIGIN in allowed_origins.
  2. Paste the returned wi_... key into the panel on the right and click Load widget.
    The key can also be passed directly in the URL: ?key=wi_....
  3. When this page is hosted separately from the AI service (e.g. on Vercel), point the widget at the API: ?key=wi_...&api-base=https://<ai-service>. By default the widget calls the API on this page's own origin.
  4. Click the launcher button (bottom-right) - the widget bootstraps, opens a chat session, and answers from the store's knowledge base.
  5. If recommendations are enabled on the installation, switch to the "Find products" tab.
  6. The status panel streams every embed event (ai-commerce-widget CustomEvent).
Provision a widget installation (curl) 
# Replace TOKEN with a SaaS admin JWT (store-scoped, roles: ["admin"])
curl -i -X POST https:///api/v1/admin/widget-installations \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"environment":"live","allowed_origins":["ORIGIN"],"scopes":["rag:chat","recommendations:read"]}'

# Response contains the widget key - it is shown only ONCE:
# { "widget_key": "wi_...", "widget_id": "wid_...", ... }
