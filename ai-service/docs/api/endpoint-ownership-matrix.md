# AI Commerce FastAPI — Endpoint Ownership Matrix

Generated from the live application OpenAPI schema (`openapi-baseline.json`, Phase A, baseline).

- Total operations: **105** across 85 paths.
- No endpoint behavior was changed to produce this matrix.
- "Redis usage" reflects direct Redis use on that route family (rate-limiting middleware and Celery broker apply globally and are noted at family level where non-obvious).
- `UNCLASSIFIED` is used wherever evidence was insufficient — there are none pending at baseline.

## Classification legend

| Class | Meaning |
|---|---|
| `STOREFRONT_WIDGET` | Browser widget on merchant storefronts; widget-key bootstrap or widget JWT |
| `INTERNAL_RAG` | The shared RAG engine, invoked by ASP.NET Core / internal callers |
| `ADMIN_SAAS` | Dashboard / SaaS backend (ASP.NET Core) with an authenticated user JWT |
| `INFRASTRUCTURE` | Health/probe endpoints |
| `UNCLASSIFIED` | Insufficient evidence — none at baseline |

## Authentication notes (baseline)

- The global `AuthMiddleware` passes requests through **without a token when `JWT_REQUIRED=false`** (the `.env` default). Every router with an explicit `Depends(get_current_user|get_current_store_id|require_*_role|...)` therefore returns 401/403 in anonymous mode, and every router **without** such dependencies (RAG, widget bootstrap) keeps working anonymously.
- Widget endpoints are protected by the widget JWT path in `AuthMiddleware` + `require_widget_scope`; bootstrap uses `X-Widget-Key`.
- Legacy `app/api/knowledge/router.py` is **not mounted** in `main.py` (dead code) — its unauthenticated `/documents|chunks|summaries|uploads` routes are not part of the live API.
